# RobustiPy website

This repository contains the public website for [RobustiPy](https://robustipy.github.io/), an open-source Python library for multiverse analysis and model uncertainty assessment.

- [Read the paper in *Patterns*](https://www.cell.com/patterns/fulltext/S2666-3899(26)00118-2)
- [Read the documentation](https://robustipy.readthedocs.io/en/latest/)
- [View the software source](https://github.com/RobustiPy/robustipy)
- [Install from PyPI](https://pypi.org/project/robustipy/)

The software is released under the [GNU General Public License v3.0](https://github.com/RobustiPy/robustipy/blob/main/LICENSE).
